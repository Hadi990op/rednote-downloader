About RedNote Video Downloader

RedNote Video Downloader is a free, open-source online tool for downloading videos from Xiaohongshu (RedNote / 小红书) without watermark. Our mission is simple: make it easy for anyone to save their favorite RedNote videos in the best available quality — no signup, no software, no cost.

How It Works

The tool uses yt-dlp, an open-source video extraction library, to fetch video metadata and download URLs from Xiaohongshu's CDN. When you paste a RedNote link, the tool:

  1. Extracts the video's note ID from the URL
  2. Fetches the page metadata from xiaohongshu.com
  3. Identifies all available video streams (720p, 1080p, 4K)
  4. Presents quality options to the user
  5. Downloads the selected quality and serves it as a clean MP4
  6. Deletes the temporary file from the server immediately after delivery

Privacy

We take privacy seriously. The tool:

  • Does not require any signup or personal information
  • Does not store downloaded videos on the server (temp files deleted immediately)
  • Does not track or collect user data
  • Does not use cookies (except for optional cookie configuration for higher quality)

Technology

The downloader is built with:

  • Python Flask — web framework for the backend
  • yt-dlp — open-source video extraction engine
  • ffmpeg — video/audio merging for higher quality formats
  • Vanilla HTML/CSS/JS — fast, lightweight frontend with no frameworks
