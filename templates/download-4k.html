Why Do I Need Cookies for 4K RedNote Downloads?

Xiaohongshu gates 1080p (Full HD) and 2160p (4K) video streams behind authentication. When you request a video without being logged in, the server only returns the 720p H.264 stream. Higher quality tiers — 1080p, 2160p/4K, H.265, AV1 — are only embedded in the page when the request carries a valid session cookie.

To unlock 4K, you need to provide your logged-in Xiaohongshu session to the downloader via cookies:

Option A: Pull Cookies from Browser (Easiest)

  1. Log into xiaohongshu.com in your browser (Chrome, Firefox, Edge, etc.)
  2. Set the environment variable: XHS_COOKIES_BROWSER=chrome (or firefox, edge, brave, etc.)
  3. Restart the downloader server

Option B: Export Cookies to File

  1. Install a browser extension like "Get cookies.txt LOCALLY" (Chrome/Edge) or "Export Cookies" (Firefox)
  2. Visit xiaohongshu.com while logged in and export cookies to a file
  3. Set: XHS_COOKIES_FILE=/path/to/xhs_cookies.txt
  4. Restart the server
